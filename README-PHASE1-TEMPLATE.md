# Phase 1 starter overlay

Copy this package over a newly generated Next.js project configured with:

- TypeScript
- ESLint
- Tailwind CSS
- App Router
- No `src` directory

Replace the generated `app/layout.tsx`, `app/page.tsx`, and `app/globals.css`.
Then run:

```powershell
npm run dev
```

Pages included:

- `/` analytics dashboard
- `/campaigns` coming soon
- `/ai-agent` coming soon
- `/settings` coming soon
